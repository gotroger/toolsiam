# ผลแก้ไขความถูกต้อง ToolSiam — 9 กันยายน 2569

แก้ข้อผิดพลาด A01–A14 จากรายงาน audit และ A15–A16 ที่พบระหว่างตรวจเตรียมเผยแพร่แล้ว โดยทดสอบบน `http://127.0.0.1:4321` ก่อนเผยแพร่; ตรวจสถานะการเผยแพร่ได้จาก [CI & Deploy](https://github.com/gotroger/toolsiam/actions/workflows/deploy.yml)

ตรวจกรอกซ้ำครบ 34 เครื่องมือและอีก 8 หน้าที่รับข้อมูล รวม 42 หน้า พร้อมหลักฐาน 64 กรณี/เส้นทางและการตรวจมือถือ 3 หน้า; ผลนี้รับรองเฉพาะกรณีและขอบเขตที่ตรวจ ไม่รับประกันทุกเงื่อนไขสัญญา สิทธิภาษี หรือการเปลี่ยนกฎหมายในอนาคต

## ขอบเขตที่ระบุให้ผู้ใช้เห็น

เครื่องมือภาษีรองรับเงินเดือนมาตรา 40(1) ปีภาษี 2568–2569; ESGX สิทธิย้าย LTF มาตรการชั่วคราว และกองทุนเกษียณอื่นยังต้องกรอกเฉพาะยอดสิทธิที่ตรวจเงื่อนไขและเพดานแล้ว โดยไม่มีการอ้างว่ารองรับค่าลดหย่อนทุกประเภทอัตโนมัติ

เงินเดือนสุทธิเป็นประมาณการเมื่อเงินเดือนคงที่ครบ 12 เดือนและเฉลี่ยภาษีทั้งปีเป็นรายเดือน ส่วนยอดสลิปจริงอาจมีเงินสะสมกองทุน รายการหัก และวิธีหักภาษีโบนัสต่างกัน

ปฏิทินวันหยุดรองรับปี 2569 เฉพาะวันหยุดทั่วประเทศและกรุงเทพฯ; ไม่รวมวันหยุดเฉพาะจังหวัดอื่นหรือวันหยุดของนายจ้างแต่ละราย

- `npm test`: ผ่าน 728/728 กรณีใน 70 ไฟล์
- `npm run typecheck`, `npm run lint`, `npm run build`: ผ่าน
- ทดสอบวันที่ อายุ และค่าชดเชยซ้ำใน timezone America/Los_Angeles: ผ่าน 38/38 กรณี
- เบราว์เซอร์: 38 กรณีกรอกฟอร์มหลัก/ปฏิทิน และ 26 กรณีที่ตรวจข้อความผลคาดหวัง รวม 64 กรณีไม่มีผลไม่ตรงที่ค้างอยู่
- QR: สร้างพร้อมเพย์ยอด 150.25 ดาวน์โหลดรูปแล้วอัปโหลดเข้าเครื่องอ่าน QR และอ่านยอดกลับได้ โดยไม่มีการโอนเงินจริง
- มือถือ 390 × 844: ตรวจภาษี เงินเดือน และวันหยุด ไม่มีหน้าเลื่อนล้นแนวนอน; ช่องภาษีผิดรูปแบบมี `aria-invalid`; ปฏิทินปิดด้วย Escape และคืน focus ไปช่องเดิม
- จัดรูปแบบไฟล์โค้ดที่แก้ด้วย Prettier แล้ว; การตรวจรูปแบบทั้งโครงการยังมีไฟล์เดิมที่ไม่ผ่าน จึงไม่รายงานว่า formatter ทั้งโครงการผ่าน
