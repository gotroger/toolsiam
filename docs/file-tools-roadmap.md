# เครื่องมือเอกสารและรูปภาพ — 9 กันยายน 2026

เพิ่ม 2 หมวด: เอกสารและแปลงไฟล์ (`documents`) และรูปภาพ (`images`)

ไฟล์ประมวลผลบนอุปกรณ์ผู้ใช้ ไม่มี upload API ไม่มีพื้นที่เก็บไฟล์บนเซิร์ฟเวอร์ และไม่มีค่า API ต่อการแปลง; การเสิร์ฟหน้าเว็บและชุด JavaScript ยังใช้ bandwidth ตามปกติ

PDF/Office ประมวลผลใน Web Worker ที่สร้างเมื่อกดเริ่มและปิดหลังจบ ยกเลิก หรือครบ 60 วินาที; ไลบรารีโหลดตามงาน ไม่โหลดตัวแปลง Office ทุกครั้งที่เปิดหน้าเครื่องมืออื่น

จำกัด PDF ไฟล์ละ 15 MB รวม 30 MB และ 150 หน้า; รูปไฟล์ละ 10 MB และ 16 ล้านพิกเซล; Office/CSV ไฟล์ละ 5 MB; Office ZIP คลายข้อมูลไม่เกิน 30 MB/2,000 entries; ตารางไม่เกิน 100,000 ช่อง; หลายไฟล์สูงสุด 20 ไฟล์รวม 30 MB

ภาพประมวลผลเรียงทีละไฟล์และคืน bitmap/canvas เมื่อจบ; รูปเป็น PDF ย่อด้านยาวไม่เกิน 2,400 พิกเซล; bitmap ต้องเปิดก่อนจึงตรวจจำนวนพิกเซลได้ จึงไม่รับประกันเพดาน RAM ของการ decode ภาพบีบอัดขนาดผิดปกติ

ข้อมูลและลิงก์ดาวน์โหลดอยู่ในหน่วยความจำจนกดล้าง เปลี่ยนค่า เปลี่ยนไฟล์ หรือออกจากหน้า; ไม่มีการบันทึกลง localStorage

ข้อจำกัด: PDF ที่เข้ารหัสไม่รองรับ; การสร้าง PDF ใหม่อาจไม่คง bookmarks, ลิงก์ข้ามหน้า, แบบฟอร์ม interactive และลายเซ็นดิจิทัล; ควรตรวจผลลัพธ์ก่อนนำไปใช้กับเอกสารประเภทนี้

CSV ส่งออกเก็บเฉพาะค่าข้อมูล ไม่เก็บรูปแบบ Excel, วันที่เป็น ISO 8601, สูตรไม่มี cache จะปฏิเสธพร้อมคำแนะนำ; ค่าที่เสี่ยงเป็นสูตรจะเติม apostrophe รวมถึงข้อความขึ้นต้น + และ -; CSV นำเข้าเก็บเป็นข้อความทั้งหมดเพื่อรักษาเลขศูนย์นำหน้าและไม่ประเมินสูตร

ภาพใช้การเข้ารหัสใหม่ อาจเปลี่ยนสีจาก color profile และไม่เก็บ metadata; รองรับภาพนิ่งเท่านั้น ภาพเคลื่อนไหวอาจได้เพียงเฟรมเดียว; ไม่รองรับ HEIC, GIF, SVG; การลดคุณภาพไม่รับประกันว่าไฟล์จะเล็กลง

## รายการที่รอให้ตัดสินใจ

รายการด้านล่างคัดจากงานที่มีอยู่ในบริการเอกสาร/ภาพที่ใช้กันแพร่หลาย ไม่มีข้อมูล search volume หรืออันดับความนิยมรายเครื่องมือของ ToolSiam และยังไม่ได้เปิดเป็นหน้าที่ใช้งานได้

| เครื่องมือ                     | ทรัพยากร/ความยาก | เหตุผลที่รอ                                        | แนวทางรอบถัดไป                                             |
| ------------------------------ | ---------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| PDF → Word รักษาเลย์เอาต์      | สูง              | ต้องสร้างย่อหน้า ตาราง ฟอนต์ และตำแหน่งกลับจาก PDF | ประเมินบริการแปลงหรือ engine เฉพาะ พร้อมต้นทุนต่อหน้า      |
| Word → PDF รักษาหน้าต้นฉบับ    | กลาง–สูง         | ต้องมี Office renderer และฟอนต์ไทยให้ตรง           | LibreOffice ใน worker server แยกพร้อมคิว                   |
| Excel → PDF รักษาการพิมพ์      | กลาง–สูง         | ต้องคำนวณสูตร พื้นที่พิมพ์ กราฟ และแบ่งหน้า        | ใช้ Office renderer เดียวกัน                               |
| PDF → Excel แยกตาราง           | สูง              | โครงสร้างตารางและ merged cells ต้องวิเคราะห์       | เริ่ม PDF ที่มีข้อความ ก่อนรองรับสแกน                      |
| OCR ไทย/อังกฤษ จาก PDF หรือภาพ | สูง              | ใช้โมเดล OCR และ CPU/RAM ตามจำนวนหน้า              | ทดสอบความแม่นภาษาไทย ต้นทุน และขีดจำกัด                    |

| ลบวัตถุในภาพ AI                | สูง              | ต้องมี mask editor และ inpainting                  | ประเมินคุณภาพและค่าใช้จ่ายก่อนสร้าง                        |

| PDF → JPG/PNG                  | กลาง             | ต้องเพิ่ม PDF renderer และจำกัดความละเอียดต่อหน้า  | ทำได้ฝั่งเบราว์เซอร์ในรอบถัดไป ไม่จำเป็นต้องใช้เซิร์ฟเวอร์ |
