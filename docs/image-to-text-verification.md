## ความแม่น — ชุดรูปจำลอง 6 แบบ

**ข้อจำกัดของการทดสอบนี้:** รูปทั้งหมดวาดด้วย canvas (ฟอนต์ Sarabun/Prompt/Georgia) ไม่ใช่ภาพถ่ายจริง
รูปที่ 3 จำลองภาพถ่ายด้วยการเอียง 4° เบลอ และใส่ noise ผลกับภาพถ่ายจากมือถือจริงจะแย่กว่านี้ — **ยังไม่ได้ทดสอบกับภาพถ่ายจริง**

| รูป                                      | ความมั่นใจ | ผิดอะไร                                                                                                                         |
| ---------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1 ภาพหน้าจอข้อความไทย 20px               | 93%        | `เรื่อง` → `เรือง` (วรรณยุกต์หาย 1 จุด) ที่เหลือถูกทั้งหมด                                                                      |
| 2 สลิปโอนเงิน พื้นเขียวอ่อน ฟอนต์ Prompt | 91%        | `เงิน` → `เจิน` · เลขบัญชีปิดบัง `xxx-x-x5678-x` เพี้ยนเป็นสัญลักษณ์ · `บาท` → `un` หนึ่งจุด · **ยอดเงินและรหัสอ้างอิงถูก**     |
| 3 เอกสารเอียง 4° + เบลอ + noise          | 90%        | มีบรรทัดขยะจาก noise 2 บรรทัด · วรรณยุกต์หายหลายจุด (`ฉบับที่` → `ฉบบที`, `ผู้เช่า` → `ผูเชา`, `ล่าช้า` → `ล่าข้า`) · ตัวเลขถูก |
| 4 ป้ายร้าน ตัวหนาใหญ่ พื้นแดง            | 93%        | `ก๋วยเตี๋ยว` → `ก๋วยเตียว` · `น.` → `u.`                                                                                        |
| 5 อังกฤษล้วน                             | 95%        | ถูกทั้งหมด รวมตัวเลขและเครื่องหมาย                                                                                              |
| 6 ไทยปนอังกฤษปนตัวเลข 14px               | 93%        | `256GB` → `25668` ที่เหลือถูก รวมเลขพัสดุและเบอร์โทร                                                                            |

ข้อสรุปที่ใช้กับข้อความบนหน้า

1. **ค่าความมั่นใจไม่สะท้อนความผิดระดับอักขระ** — ทุกรูปได้ 90%+ ทั้งที่มีคำผิด เกณฑ์ `LOW_CONFIDENCE = 60` จึงจับได้แค่รูปที่เสียหนัก
   → เพิ่มบรรทัดเตือนถาวรใต้ผลลัพธ์ว่า "ความมั่นใจสูงไม่ได้แปลว่าถูกทุกตัว"
2. จุดอ่อนจริงคือ **วรรณยุกต์/สระบนล่างหาย** และ **ตัวอักษรละตินปนตัวเลข** (`GB` → `68`, `น.` → `u.`) — ตรงกับ disclaimer ใน `meta.ts`
3. ตัวเลขจำนวนเงินในชุดนี้ถูกทุกจุด แต่ตัวอย่างน้อยเกินจะรับรอง — disclaimer ยังบอกให้ตรวจตัวเลขเสมอ
4. "จัดช่องว่างภาษาไทย" ทำให้ช่องว่างจริงหาย (`ใบเสร็จรับเงิน เลขที่` → `ใบเสร็จรับเงินเลขที่`) ตามที่สเปกยอมรับไว้ ปิดได้

## ยังไม่ได้ตรวจ

- ภาพถ่ายจริงจากมือถือ (สลิปจริง เอกสารกระดาษ ป้ายกลางแจ้ง)
- มือถือจริงทั้ง Android และ iPhone — โดยเฉพาะแรมกับรูป 10 รูปติดกัน และรูป 48 MP ก่อนย่อ
- Safari และ Firefox (ตรวจเฉพาะ Chromium)
- เลือก "อังกฤษ" แล้วไม่โหลด `tha` — ยืนยันจากโค้ด (`createWorker(lang.split('+'))`) และ test ของ engine ไม่ได้ดูจาก network ใน worker
- cache ครั้งที่สองบน production (`/ocr/*` immutable) — ตรวจ header หลัง deploy
