# วิธีเพิ่มผลรางวัลสลากกินแบ่งรัฐบาลหนึ่งงวด

ไฟล์ข้อมูล: `src/lottery/data/draws.ts` — เป็นแหล่งความจริงเดียวของทั้งหมวดหวย
หน้า `/lottery`, `/lottery/check`, `/lottery/results`, `/lottery/results/<วันที่>` และ `/lottery/archive`
generate จากไฟล์นี้ทั้งหมด ไม่ต้องแก้ไฟล์หน้าเว็บเลย

> **กติกาข้อเดียวที่ห้ามผิด:** ตัวเลขทุกตัวต้องคัดจากประกาศของสำนักงานสลากกินแบ่งรัฐบาล
> โดยเปิดประกาศจริงมาเทียบทีละบรรทัด ห้ามคัดจากเว็บอื่นต่อ ๆ กันมา และห้ามเดา
> — ไม่มีข้อมูลดีกว่าข้อมูลผิด เพราะผู้ใช้เอาไปตัดสินใจเรื่องเงินจริง

## ขั้นตอน

1. เปิดประกาศผลรางวัลของงวดนั้นจาก [สำนักงานสลากกินแบ่งรัฐบาล](https://www.glo.or.th/)
2. เพิ่มอ็อบเจ็กต์หนึ่งก้อนในอาร์เรย์ `draws`

```ts
{
  date: '2026-09-16', // วันออกรางวัลเป็น ค.ศ. เสมอ (พ.ศ. 2569 = ค.ศ. 2026)
  results: [
    { id: 'first',       amount: 6_000_000, numbers: ['123456'] },
    { id: 'second',      amount: 200_000,   numbers: [/* 5 เลข */] },
    { id: 'third',       amount: 80_000,    numbers: [/* 10 เลข */] },
    { id: 'fourth',      amount: 40_000,    numbers: [/* 50 เลข */] },
    { id: 'fifth',       amount: 20_000,    numbers: [/* 100 เลข */] },
    { id: 'front-three', amount: 4_000,     numbers: ['123', '456'] },
    { id: 'last-three',  amount: 4_000,     numbers: ['789', '012'] },
    { id: 'last-two',    amount: 2_000,     numbers: ['56'] },
  ],
  source: {
    name: 'ประกาศสำนักงานสลากกินแบ่งรัฐบาล',
    url: 'https://www.glo.or.th/...',
    verifiedAt: '2026-09-16', // วันที่คุณเปิดประกาศมาเทียบ
  },
}
```

3. งวดแรกที่เพิ่มเข้าระบบ ให้เปลี่ยน `LOTTERY_HAS_RESULTS` ใน `src/lib/noindex.ts` เป็น `true`
   (หน้าที่พึ่งข้อมูลงวดถูกกัน noindex ไว้ตอนยังไม่มีข้อมูล — เทสต์จะฟ้องถ้าลืม)
4. `npm test` — `src/lottery/draws.test.ts` ตรวจให้อัตโนมัติว่า
   จำนวนเลขครบตามประกาศ · จำนวนหลักถูก · ไม่มีเลขซ้ำ · วันที่มีจริง · มีที่มาและวันที่ตรวจข้อมูล
5. `npm run build` แล้วเปิด `/lottery/results/<วันที่>` ดูด้วยตาอีกครั้ง

## จุดที่พลาดกันบ่อย

- **เลข 0 นำหน้า** — ต้องเป็นสตริงเสมอ (`'012345'` ไม่ใช่ `12345`)
- **รางวัลข้างเคียงรางวัลที่ 1** ไม่ต้องกรอก ระบบคำนวณจากรางวัลที่ 1 (±1 และวนรอบที่ 6 หลัก) ให้เอง
  ถ้ากรอกเองจะใช้ค่าที่กรอกแทน
- **เงินรางวัลของงวดพิเศษ** ที่จ่ายไม่เท่าโครงสร้างมาตรฐาน ให้ใส่ `amount` ตามประกาศของงวดนั้น
  ไม่ต้องแก้ `src/lottery/prizes.ts` ซึ่งเป็นโครงสร้างมาตรฐาน
- **งวดที่เลื่อนวันออกรางวัล** ให้บันทึกใน `src/lottery/data/schedule.ts` ด้วย
  ปฏิทินในหน้า `/lottery` จะขยับตามทันที

## ตรวจโครงสร้างรางวัลก่อน launch

`src/lottery/prizes.ts` และ `src/lottery/prize.ts` มีตัวเลขที่ยัง **ไม่ได้ตรวจกับประกาศจริง**
(จำนวนรางวัลแต่ละชั้น เงินรางวัลต่อรางวัล อากรแสตมป์ และภาษีสลากการกุศล)
ทั้งสองไฟล์มีค่า `verifiedAt: ''` กำกับไว้ — ตรวจแล้วให้ใส่วันที่ลงไป
