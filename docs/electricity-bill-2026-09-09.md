# ตรวจและแก้ค่าไฟตามเดือนบิล — 9 กันยายน 2569

ปัญหาเกิดจากการนำอัตราปัจจุบันเดือนกันยายนไปใช้เทียบบิลสิงหาคม และคำนวณ VAT จากค่าพลังงานกับ Ft ที่ยังไม่ปัดเป็นสตางค์ ทำให้บิลเก่าคลาดเพิ่ม 1 สตางค์

เพิ่มตัวเลือกเดือนบิลมกราคม–ธันวาคม 2569 โดยอัตราฐานเปลี่ยนในบิลกันยายน และ Ft เปลี่ยนตามงวดที่ประกาศ; วันที่ไม่มีข้อมูลไม่แสดงยอดประมาณการจากอัตราอื่น

ปัดค่าพลังงานรวมและ Ft เป็นสองตำแหน่งก่อนรวมฐานภาษี จากนั้นปัด VAT และบวกยอดที่ปัดแล้ว พร้อมแสดงค่าไฟฟ้าฐานรวมค่าบริการและยอดก่อน VAT ให้เทียบชื่อรายการในใบแจ้งค่าไฟได้

กรณีทดสอบที่ตัดข้อมูลส่วนบุคคลออก: PEA บ้านอยู่อาศัยอัตราเกิน 150 หน่วย บิลสิงหาคม 2569 จำนวน 871 หน่วย

| รายการ      |      บาท |
| ----------- | -------: |
| ค่าพลังงาน  | 3,625.33 |
| ค่าบริการ   |    24.62 |
| ค่าไฟฟ้าฐาน | 3,649.95 |
| Ft          |   141.36 |
| ก่อน VAT    | 3,791.31 |
| VAT         |   265.39 |
| รวม         | 4,056.70 |

เดือนกันยายน จำนวนหน่วยเท่ากันได้ 3,905.95 บาท ตามโครงสร้างใหม่

การตรวจ: unit tests ครอบคลุมรายการบิล 871 หน่วย ขอบเขตเดือนเปลี่ยนอัตรา/Ft วันที่ไม่มีข้อมูล และยอดรวมรายการที่ปัดเศษ; ชุดทดสอบรวม 69 ไฟล์ 702 tests ผ่าน พร้อม lint และ typecheck ผ่าน; browser ตรวจการสลับสิงหาคม/กันยายนและยอดทุกรายการบนหน้าจอจริง
